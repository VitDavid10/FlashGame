El copy real de cada mensaje del juego (mismo texto por defecto que usa la partida). Edítalo aquí — se guarda solo — y pulsa "VER EN UI" para saltar a la pestaña "UI del juego" y disparar ese cuadro con tu texto. Si el juego aún no está cargado ahí, pulsa antes "MOSTRAR UI (ARCADE)".
Estás abriendo esta página como archivo suelto (file://). Esta pestaña necesita servirla por HTTP (node server/index.js y entrar por http://localhost:PUERTO/game/font-preview.html) porque el navegador bloquea el acceso entre páginas locales sueltas.
